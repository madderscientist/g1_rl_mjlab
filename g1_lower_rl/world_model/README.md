# 全身位置控制 WM v3

固定闭合双 Gloria-M 夹爪 G1 的可微动力学模型：**29个运动关节、44个刚体、50Hz**。
每次预测将实际关节位置目标保持20ms，对应原生仿真的4个5ms子步。

## 预训练权重

GitHub Release 提供 `g1_wm.pt` 和同名 `.json`：

- 预训练最佳检查点 **update 31750**。
- **19,353,676个参数，完整FP32**；包含全部固定归一化buffer及物理契约，不含Adam。
- 冻结原生22650策略产生动作，MuJoCo生成标签；采集采用原生位置执行器，**无显式手臂GC**。
- 全库98,049条动作 / 32,440,430帧，训练96,152、留出1,897；累计213,360,640条转移。
- 固定留出窗口160ms归一化状态RMSE为 **0.4232774624**，不是米/弧度或策略闭环分数。

```python
from g1_lower_rl.world_model import load_world_model

model = load_world_model("path/to/g1_wm.pt", device="cpu").train()
prediction = model(state71, actual_joint_target29, context48)
```

输入使用原始物理单位，归一化和输出还原在模型内部完成，**不要重复归一化或重新拟合统计量**。
权重放入本目录的 `checkpoints/` 后可省略路径；JSON为可选接口说明。
加载会校验检查点、物理契约和归一化。
使用 `--initialize` 新建Adam继续训练，见[训练说明](training/README.md)。

## 输入：145维

| 项目 | 维度 | 单位/坐标系 |
|---|---:|---|
| pelvis高度 | 1 | m，相对环境原点 |
| 重力方向 | 3 | 根部系单位向量 `R(q)^T (0,0,-1)` |
| 根部线速度、角速度 | 3 + 3 | 根部系，m/s、rad/s |
| 真实关节位置、速度 | 29 + 29 | rad、rad/s，无观测偏差或噪声 |
| 实际关节位置目标 | 29 | rad，不是归一化策略动作 |
| 逐刚体实际质量 | 44 | kg，包含夹爪及手部额外负载 |
| 左右共享足摩擦 | 1 | 无量纲 |
| torso局部COM偏移 | 3 | m，相对名义质心 |
| **合计** | **68 + 29 + 48 = 145** | |

关节和刚体必须按 [model.py](model.py) 的 `JOINT_NAMES`、`BODY_NAMES` 对齐。
网络不接收绝对XY/yaw、`dt`、惯量、编码器偏差或独立负载维度。
模型以实际质量条件化，惯量差异属于未显式条件化的建模近似。

目标必须与真实执行一致：执行噪声 → 缩放/偏移 → 裁剪 → 减编码器偏差 →
可选GC补偿 → 原生目标范围裁剪。WM只接收最后的实际目标，并保持20ms。
动作数据按规范顺序读取29个机器人关节，不按夹爪开合筛选帧；
仿真包含固定夹爪的质量与几何。

## 输出与积分

网络原始输出为 **76维**，乘固定尺度后按以下方式解释：

| 切片 | 含义 | 单位/坐标系 |
|---|---|---|
| `0:3` | 根部位置修正 `c_p` | m，当前根部系 |
| `3:6` | 旋转向量修正 `c_theta` | rad，本体系右复合 |
| `6:35` | 关节位置修正 `c_j` | rad |
| `35:38` | 线速度变化 `delta_v` | m/s，当前根部系 |
| `38:41` | 角速度变化 `delta_omega` | rad/s，本体系分量之差 |
| `41:70` | 关节速度变化 `delta_qd` | rad/s |
| `70:76` | 左脚XYZ、右脚XYZ接触合力 | N，**下一**根部系 |

设 `R_t` 为当前根部到世界的旋转，`h=0.02`：

```text
v_world_next = v_world + R_t * delta_v
omega_body_next = omega_body + delta_omega
qd_next = qd + delta_qd
p_world_next = p_world + h * v_world_next + R_t * c_p
quat_next = normalize(quat * ExpQuat(h * omega_body_next + c_theta))
qj_next = qj + h * qd_next + c_j
```

零更新对应匀速外推。`state_update(state, next_state)`按同一公式反解标签。
完整外部状态为71维：世界位置3、wxyz四元数4、关节位置29、世界线速度3、
本体角速度3、关节速度29；世界位置和姿态仅用于网络外积分、FK与任务。

`prediction.state` 为 `[...,71]`，`.foot_force_root` 和 `.foot_force` 分别为下一根部系/
世界系 `[...,2,3]` 足力；`.as_tensor()`拼接完整状态与世界足力，因此是 **77维**。
`predict_updates(pack_inputs(...)).as_tensor()`返回76维原始更新。

## 使用边界

- 足力标签取**最后物理子步**的接触解，不是20ms平均力；用真实下一姿态转换监督坐标系。
  根部系Fz在倒立时可以为负，接触和竖直力判定必须使用世界系。
- 足力不包含接触力矩、自碰撞或接触点；阈值接触不保证等同原生传感器事件。
- 固定执行器参数、采集覆盖及物理来源见发布JSON。独立左右摩擦、未入模外力或其他
  控制参数随机化不能静默视为匹配v3。
- 加载要求：检查点格式2、物理协议3、固定29关节位置控制接口。
- 开放环误差不证明长时稳定、真实动力学梯度准确或策略收益，接入仍需原生闭环验证。

采集、replay、归一化与恢复见[训练说明](training/README.md)；
可微FK、GC、接触及三任务接口见[适配器说明](adapters/README.md)。
