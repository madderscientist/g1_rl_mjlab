# 脚步跟踪训练

任务 `G1-Gloria-FootstepTracking` 已注册，可通过现有训练入口启动

```bash
micromamba run -n mj python scripts/train.py G1-Gloria-FootstepTracking \
  --gpu-ids '[0]' --env.scene.num-envs 64
```

actor 输入84维，模型内部编码到89维，经 GRU(32) 和 MLP(256,128) 输出15轴动作
观测顺序为29轴绝对角、29轴速度、骨盆角速度/重力、躯干角速度/重力、相位、频率、四步 XY/yaw
不输入夹爪、上一拍动作或身体高度指令；critic 为104维，额外包含线速度、接触和上一拍动作
动作沿用 G1 的12腿+3腰位置增量映射；已有15项脚步奖励全部启用

## 当前奖励

以下以 [rewards_cfg.py](rewards_cfg.py) 和 [rewards.py](rewards.py) 为准，列出当前启用的全部15项，
不是速度跟踪任务奖励的拷贝，也不是已经收敛调优的权重
常规项的实际单拍贡献为 `weight * raw_value * step_dt`，当前 `step_dt=0.02s`
唯一例外是 `fall`：原始值内部除以 `step_dt`，所以每次非超时终止固定扣10分
`Episode_Reward/*` 是管理器累计后的归一化日志，不应直接当作原始项数值或单次事件分数

### 脚印精度

| 项 | 权重 | 当前定义 |
| --- | ---: | --- |
| `footstep_landing` | +4.0 | 行走时锁定该目标首次离地后触地的 XY/yaw 精度，只在后续实际接触的计划支撑期计分；f=0 时改为实时双脚保持精度 |
| `footstep_support` | +1.0 | 当前实际接触的计划支撑脚，相对原目标的实时 XY/yaw 精度 |
| `footstep_approach` | -0.5 | 摆动脚到目标的平面距离乘摆动进度平方，提供远离目标时的引导；f=0 时关闭 |

单脚精度核为

$$
S=\tfrac12\exp\left[-\left(\frac{\lVert p_{xy}-p^*_{xy}\rVert}{0.08}\right)^2\right]
+\tfrac12\exp\left[-\left(\frac{\operatorname{wrap}(\psi-\psi^*)}{0.20}\right)^2\right]
$$

位置尺度为0.08m，朝向尺度为0.20rad（约11.46度）；XY整体位置与yaw各占50%，独立指数评分后相加
X/Y不再拆成两项，保持平面旋转不变性；同一个核用于落地锁分、支撑精度和f=0站立保持
单脚最高分仍为1，外层落地+4、支撑+1和其余13项权重不变；部分失配时得分与旧联合指数不同，
新旧run应对比原始落点/yaw误差和存活率，不能仅比较总奖励，也不能把只做好一项当作成功
两项精度奖励均按计划支撑脚数量取平均，实际未接触的脚得0，不能靠只接触一只脚拿双支撑满分
行走落地分要求该脚先在计划摆动期离地，再发生第一次接触；接触须在理论落地中心的许可窗口内
默认中心为左脚 pi/2、右脚3pi/2，许可半宽为0.1个完整周期，即中心前后各36度
一般配置下许可半宽为 `max(0.25 * 该脚摆动周期占比, contact_half_width/(2*pi))`
超窗首次接触锁为0，落地后滑到目标或再次抬落不能改写同一目标的首次成绩；reset 按环境清空历史
落地核在支撑期作为奖励率累计，不是每次触地单独发一次固定奖金
站立时两项都使用实时双脚精度，合计最高5.0奖励率，不要求站立 reset 后先抬脚

### 步态与接触

| 项 | 权重 | 当前定义 |
| --- | ---: | --- |
| `contact_schedule` | +2.0 | 两只脚的实际接触都匹配计划接触模式时才得1；f=0 始终要求双接触 |
| `swing_clearance` | -0.5 | 摆动脚低于相位相关离地间隙的归一化平方代价，高于目标不再收费；f=0 关闭 |
| `foot_slip` | -2.0 | 实际触地脚的平面速度模长，加0.05m乘竖直轴角速度绝对值，再对两脚求和 |
| `soft_landing` | -0.002 | 复用速度跟踪的首次触地 XYZ 接触力模长之和，不使用 twist 或频率门控 |

`swing_clearance` 的原始值为

$$
\sum_{\text{摆动脚}}\left[\frac{\max(0,\ 0.08\sin(\pi s)-(z-z_{ground}))}{0.08}\right]^2,
\qquad s\in[0,1]
$$

这是足端离地引导，不是身体高度控制；当前平地 `z_ground=0`
`foot_slip` 使用速度一次方，不是速度平方；站立、原地踏步和行走都生效
`soft_landing` 按 `compute_first_contact(dt=step_dt)` 判定，读取本拍接触力快照，不是物理子步峰值或冲量
持续支撑不收落地力度代价，首次触地即使错过目标或不满足计划相位也收费
足底传感器必须提供 `found/force` 并开启 `track_air_time=True`
其 `Metrics/landing_force_mean` 为当前拍首次触地脚的平均力模长，无触地时为0，不是整段训练的事件平均

默认相位窗口由共享 `FootstepPhaseCfg` 定义，区间左闭右开：

| 相位 | 计划接触 |
| --- | --- |
| `[0,0.4*pi)` | 右支撑、左摆动 |
| `[0.4*pi,0.6*pi)` | 双支撑，左理论落地中心 pi/2 |
| `[0.6*pi,1.4*pi)` | 左支撑、右摆动 |
| `[1.4*pi,1.6*pi)` | 双支撑，右理论落地中心3pi/2 |
| `[1.6*pi,2*pi)` | 右支撑、左摆动，跨零继续 |

计划接触在落地中心之前开始，中心用于消费未来队列，不是实际首次接触判据
f 是完整左右周期频率，不是总步频；f=0 时覆盖相位窗口为双支撑，但所有非步态关闭项仍照常计算

### 铜损与腰部姿态

| 项 | 权重 | 当前定义 |
| --- | ---: | --- |
| `lower_body_copper_proxy` | -0.5 | 仅15个受控执行器的实际力矩平方和，所有轴共用100Nm数值尺度，默认各轴系数1 |
| `waist_yaw_zero` | -0.4 | 腰 yaw 绝对关节角平方，目标0rad，不是相对默认姿态的偏差 |
| `waist_roll_pitch_edges` | -2.0 | 腰 roll/pitch 靠近硬限位两侧各15%行程时的边缘平方惩罚，中央70%为0 |
| `torso_upright` | -0.5 | torso 重力方向的水平分量平方和，即相对竖直倾角的 sin 平方，不惩罚世界 yaw |

$$
C_{\tau}=\sum_{j\in\text{腿+腰}}w_j\left(\frac{\tau_j}{100\,\mathrm{Nm}}\right)^2
$$

力矩按执行器名称解析，不用关节下标访问 actuator_force；排除手臂、夹爪和外部约束力
这是控制拍采样的力矩平方代理，不是物理子步 RMS 或真实铜损瓦特数；也不按各轴峰值力矩分别归一化
有电机标定后可以传入15轴完整命名的正 `copper_weights`，当前默认权重未经闭环能耗验证

腰边缘单轴成本为（`m=0.15*(q_max-q_min)`）

$$
C_{edge}=\max\left(0,\frac{q_{min}+m-q}{m}\right)^2+
\max\left(0,\frac{q-q_{max}+m}{m}\right)^2
$$

到硬边界时单轴成本为1，越界继续增大；两轴求和，不强迫中央区域的腰 roll/pitch 回零
腰 yaw 回零指相对骨盆的扭腰角，不锁定整个机器人世界朝向；当前没有额外的身体 heading 跟踪项

### 平滑与安全

| 项 | 权重 | 当前定义 |
| --- | ---: | --- |
| `action_rate` | -0.02 | 15维动作相邻控制拍差的平方和 |
| `controlled_joint_acc` | -2.5e-7 | 仅15个受控关节的加速度平方和，排除被外部控制的上肢与夹爪 |
| `self_collisions` | -2.0 | 复用 lower_body 腿间自碰撞传感器，累计当前历史窗口中存在超过10N接触的子步数 |
| `fall` | -10/次 | 所有非 time-out 终止，包括摔倒、塌坐以及 `footstep_fault`，不是只判断跌倒 |

终止条件依次为：脚步接触确认超时、episode 达到60s、骨盆倾角超过70度、骨盆相对最低足底低于0.35m
低高度仅为塌坐判据，没有身体高度跟踪、默认腿姿态回归、强制直膝或线速度跟踪奖励
常规项仍会在终止拍计算，因此该拍总奖励不一定恰好为-10；单纯 time-out 不触发 `fall`
这套带权目标不构成安全约束保证，需要看落地误差、存活、冲击力和力矩分项评估，不能只看总奖励

## 观测噪声

在速度跟踪 `lower_body` 观测配置基础上复用噪声量级，时序则与其 GRU 版本一致：不加随机延迟
训练 actor 开启，critic 和 play 关闭观测噪声；既有编码器偏置事件仍保留，critic/play 的关节角也仍由
`joint_pos_biased` 读取，因此“关闭观测噪声”不等于关闭编码器域随机化

| 输入 | 每拍零均值高斯标准差 | 偏置 |
| --- | ---: | --- |
| 29轴关节角 | 0.006rad | 既有 startup 编码器偏置 U[-0.015,0.015]rad |
| 29轴关节速度 | 0.87rad/s | 不额外添加 |
| 骨盆与torso角速度，各3轴 | 0.115rad/s | 每episode独立 N(0,0.03²)rad/s |
| 骨盆与torso重力方向，各3轴 | 0.029 | 每episode独立 N(0,0.01²) |
| 脚印、相位、频率 | 不加噪声 | 不添加 |

两个IMU和各分量独立采样，偏置在episode内固定，局部reset只重采对应环境
噪声项使用 `operation="abs"` 重采偏置，避免底层默认加法使偏置跨episode累积；这里只调整脚步任务，
不更改已有速度任务。重力观测加噪后不重新归一化，与速度任务同样采用分量加法近似姿态测量误差

原先每个IMU的6维项拆为角速度/重力两个3维项，以兼容NoiseModel首次读取前的reset缓冲
最终拼接仍为84维，两个IMU仍占 `[58:70]`；不引入夹爪或额外历史帧，部署模型不自行加噪声
相位、参考系转换、接触估计和通信延迟的误差尚未由这些噪声覆盖，不能用它替代真实状态估计验证

## 时序

- 第一个终止项 `footstep_fault` 在物理步后刷新运动学，调用一次执行器并发布 `update.completed` 奖励快照
- 奖励使用刚结束一拍的频率和切换前目标，不用后移的未来四步代替当前支撑目标
- 接触确认超时只终止对应环境，仍计算本拍奖励；不要移除该终止项或把推进挪到奖励之后
- reset 先标记环境，待 `sim.forward()` 后才读取实测脚位和初始航向重建队列
- 常规 command 回调只完成 reset；读观测不会推进相位，普通换步/停走不重置 GRU
- 每个环境独立持有 source/manager 随机流和状态，局部 reset 不影响其他环境

## Mind Your Steps 对照与改进建议

以下是研究对照；2026-09-16已将XY/yaw精度核改成等权分项相加，其余建议及课程尚未启用
依据为[论文v1的IV-B/IV-C及附录D/F/G](https://arxiv.org/html/2606.08253v1)，以及作者公开仓库
[固定提交6f7749b的奖励实现](https://github.com/MontenegroAlessandro/loco-mujoco/blob/6f7749be9eaa2584b9d53620ff35797654502644/loco_mujoco/core/reward/foot_placement.py)
公开配置和论文表格存在差异，代码里有分支不代表该实验权重非零；此处只阅读源码，没有复现实验

### 论文使用的目标

优化算法是非对称actor-critic PPO，策略裁剪目标、价值损失和熵项属于优化器损失；脚印目标通过奖励进入return，
不是拿脚印监督GRU的回归损失，也不依赖动作捕捉参考轨迹

| 设计 | 论文/实现 | 对我们的启发 |
| --- | --- | --- |
| 摆动脚跟踪 | XY位置、Z高度、yaw各自指数核，加权相加，摆动期间连续提供跟踪分 | 已借鉴XY/yaw分项评分，摆动稠密引导仍使用原距离进度项，不增加Z目标 |
| 支撑脚精度 | 论文保留落地时的摆动精度作为支撑期分数；公开代码在摆动角色切换时缓存上一摆动分，不是按实际首接触边沿锁分 | 我们已有实际落地锁分和实时支撑项，保留防滑移补分的语义，不照搬触发时刻 |
| 节拍 | 相位窗口内奖励对应脚离地 | 当前全接触模式严格匹配更苛刻；可比较分别对摆动脚/支撑脚计分，以改善早期探索 |
| 膝盖净空 | 摆动膝低于目标高度加余量才受影响 | 论文平地配置关闭该项，第一版平地没有必要增加抬膝姿态约束 |
| 姿态和稳定 | 名义上肢姿态、身体高度、重力水平分量、关节运动/动作平滑等 | 仅借鉴不与上肢独立扰动、无高度目标冲突的项 |
| 力矩和能量 | 公开实现含力矩平方和正机械功率 `sum max(tau*dq,0)` | 机械功率不是铜损，静态持重可有功率0但铜损非零；我们仍以15轴力矩平方代理为主 |

摆动脚的核心奖励形式为

$$
r_{sw}=w_{xy}e^{-k_{xy}\|e_{xy}\|^2}+w_ze^{-k_ze_z^2}+w_\psi e^{-k_\psi e_\psi^2}
$$

原先XY/yaw使用乘积形式 `exp(-e_xy²/std_xy²-e_yaw²/std_yaw²)`，任一项严重失配都会压低整个分数
现已使用 `0.5*exp(-e_xy²/std_xy²)+0.5*exp(-e_yaw²/std_yaw²)`，保持奖励最高总分不变
例如20cm位置误差、8cm核宽且yaw正确时，原联合核约0.00193，分项核约0.50097，朝向改善不再被位置项屏蔽
分项比例50/50是当前初值，不代表已证明最优；后续训练需要对比原始误差、存活和铜损代理
联合指标仍可作为最终两项都满足的成功率评价，不能只看分项奖励高就认定落地精确
这里说的是PPO获得的奖励区分信号，不是通过仿真器直接反传空间梯度

摆动阶段的稠密XY/yaw引导也值得与我们现有距离进度惩罚比较，但不宜从起脚瞬间就强迫脚贴最终落点，
否则可能诱导急摆/拖脚，与低力矩目标冲突；真实落地和接触约束继续保留

的摆动XY/yaw各4、sharpness各100、抬脚6、动作差分-1、力矩平方-2e-4、正机械功率-2e-3；
[G1配置](https://github.com/MontenegroAlessandro/loco-mujoco/blob/6f7749be9eaa2584b9d53620ff35797654502644/experiments/humanoid_foot_placement/train/conf_g1.yaml)

### 他们的课程

有：论文明确先在平地 `z_min=z_max=0` 学平面跟踪，再从该策略微调到3D落脚/地形
平地阶段不使用足端Z跟踪和膝高项，平地hold概率0.1；附录楼梯训练为前后走、高度±0.15m且hold概率0
3D阶段用可移动支撑柱提供目标接触面，附录还描述落地末段允许支撑柱水平跟随足端以缓解早期失败
这是训练辅助，不证明策略已经能严格踩中不可移动地面上的目标；我们不应移动既定脚印掩盖误差

这不是我们当前缺失的上肢扰动质量门控课程；所核对公开YAML的 `num_curriculum_steps=1` 也不能当成多档课程
对当前纯平地任务，更适合先学短中步、较窄频率范围，然后按原始落点/yaw误差和存活质量逐步放开
方向切换、频率范围和上肢扰动，保留容易样本；不需要为模仿论文而增加身体高度控制或3D地形
具体阈值、分布和课程仍待决定，本轮没有修改

### f=0 已有奖励与可借鉴项

当前并非只冻结时钟：`footstep_landing` 从历史锁分切到实时双脚保持，清空历史，
与support合计最高5奖励率；schedule始终要求双脚接触，最高2；approach/clearance关闭
其余铜损、腰姿态/边缘、滑移、落地力度、平滑和非超时终止惩罚保持生效
重新起步后再次要求先离地再触地，不沿用站立前锁分

论文公开奖励代码在 `still_phase && num_gaits>=2` 进入hold：抬脚分切成双脚接触分，
动作差分惩罚加倍，名义姿态约束扩展到全部关节，并仅在hold时启用可选的双脚yaw一致/身体对齐项
T1配置这些yaw项非零，G1配置为0；不能概括成每个模型都用了这些约束
论文描述的相位特征 `[0,0]` 是专门的站立标记，不是相位角x=0；我们用f=0，仍保留冻结相位的sin/cos

| 速度跟踪里的站立处理 | 当前脚步任务 | 建议 |
| --- | --- | --- |
| action_rate额外-0.08，叠加普通-0.02 | 当前只有普通-0.02 | 优先考虑f=0专用增量，先轻量或渐入，避免停走瞬间压制必要调整 |
| 站立防滑 `-4 * sum(speed)` | 当前全程 `-2 * sum(speed+0.05*abs(yaw_rate))` | 站立滑移仍明显时可加重，但脚印保持已有位置约束，不应无依据重复堆权重 |
| 站立腰角L1、腰力矩项 | 腰yaw回零、roll/pitch边缘和15轴铜损全程生效 | 不复制腰roll/pitch全程回零；若有站立扭腰，最多单独加强yaw |
| hip_yaw回零/固定姿态 | 当前脚掌yaw直接跟目标 | 不直接抄，可能与有朝向的终止脚印冲突 |
| stand_still_feet按离地脚数收费 | 当前双接触评分及两脚实时保持已降低离地收益 | 先看恢复迈步与不必要踏步的实际表现，再决定是否增加 |

站立总分高并不意味着身体完全不晃：腿可以在脚不动时摆动骨盆，当前没有站立专用身体速度项
优先增加站立速度/角速度、滑移、力矩和动作变化的监测，再决定是否轻罚骨盆平面速度和躯干角速度
不得强迫外部控制的手臂静止，不加入身体高度目标；站立增量严格由f=0触发，不能将小正频率误判为站立
